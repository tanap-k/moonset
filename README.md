# moonset

เครื่องมือประเมินหุ้นรายตัว: ใส่ชื่อหุ้น → ดึงงบ 12 ค่า → คำนวณตัวชี้วัด → ให้คะแนนคุณภาพ → หาราคาที่เหมาะสม

## ติดตั้ง (ครั้งแรกครั้งเดียว)
1. ติดตั้ง Python 3.10 ขึ้นไปจาก python.org (ตอนติดตั้งให้ติ๊ก **Add Python to PATH**)
2. เปิด Command Prompt ในโฟลเดอร์นี้ แล้วรัน
   ```
   pip install -r requirements.txt
   ```

## ใช้งานแบบหน้าเว็บ (แนะนำ)
ดับเบิลคลิก `run_web.bat` หรือรัน
```
streamlit run app.py
```
เบราว์เซอร์จะเปิด http://localhost:8501 ให้อัตโนมัติ — ใส่ชื่อหุ้นทางซ้ายแล้วกด **วิเคราะห์**
- ใส่หลายตัวพร้อมกันได้ จะมีตารางเปรียบเทียบและแท็บแยกรายตัว
- ปรับสมมติฐาน (อัตราคิดลด, MOS ฯลฯ) ด้วยแถบเลื่อน แล้วกดวิเคราะห์ใหม่
- ดาวน์โหลดผลเป็น Excel ได้จากปุ่มท้ายหน้า
- ลองแบบไม่ต่อเน็ต: `set MOONSET_DEMO=1` แล้ว `streamlit run app.py` ใส่ `DEMO.BK, DEMOE.BK`

## เปิดบนเว็บ (Streamlit Community Cloud)
1. เข้า [share.streamlit.io](https://share.streamlit.io) ล็อกอินด้วย GitHub
2. กด **Create app** → เลือก repo `tanap-k/moonset`, branch `main`, Main file `app.py`
3. กด **Deploy** รอ 2–3 นาที จะได้ลิงก์ไว้เปิดจากมือถือ
- แก้โค้ดบน GitHub เมื่อไร เว็บจะอัปเดตตามเอง
- ถ้าขึ้น "Too Many Requests" แปลว่า Yahoo จำกัดการดึงจากเซิร์ฟเวอร์ ให้รอสักพักแล้วลองใหม่ ผลที่ดึงแล้วจะถูกเก็บไว้ 6 ชั่วโมง

## ใช้งานแบบ command line
```
python moonset.py PTTEP.BK
python moonset.py CPALL.BK AOT.BK ADVANC.BK     (ทีละหลายตัว)
python moonset.py AAPL --type growth --r 0.09   (หุ้นอเมริกา + ปรับสมมติฐาน)
```
- หุ้นไทยต้องเติม `.BK` ท้ายชื่อ
- ผลลัพธ์แสดงบนหน้าจอ และบันทึกเป็น Excel ในโฟลเดอร์ `output/`

| ตัวเลือก | ความหมาย | ค่าตั้งต้น |
|---|---|---|
| `--type` | บังคับประเภท: growth / dividend / cyclical / stable | จัดกลุ่มอัตโนมัติ |
| `--r` | อัตราคิดลด (ผลตอบแทนที่ต้องการ) | 0.10 |
| `--mos` | Margin of Safety | 0.25 |
| `--pe` | P/E เหมาะสม (ใช้กับหุ้นวัฏจักร) | 10 |
| `--g` | การเติบโตระยะยาว | 0.03 |

## ขั้นตอนการคำนวณ

**1. ข้อมูล 12 ค่า** จาก Yahoo Finance: รายได้, กำไรจากการดำเนินงาน, กำไรสุทธิ, ภาษี, เงินสด, หนี้ที่มีดอกเบี้ย, ส่วนของผู้ถือหุ้น, จำนวนหุ้น, เงินสดจากการดำเนินงาน, CapEx, ปันผลจ่าย, ราคา
- ถ้างบเป็นสกุลเงินอื่น (เช่น PTTEP รายงานเป็น USD) จะแปลงเป็นสกุลของราคาให้อัตโนมัติ

**2. เกณฑ์ตัดทิ้ง**: ขาดทุนบ่อย, FCF รวมติดลบ, D/E > 2, จำนวนหุ้นเพิ่ม > 10%

**3. คะแนนคุณภาพ (เต็ม 10)** ด้านละ 0–2
| ด้าน | 2 | 1 | 0 |
|---|---|---|---|
| ROIC เฉลี่ย | > 15% | 8–15% | < 8% |
| EPS โตต่อปี | > 10% | 0–10% | ติดลบ |
| ความสม่ำเสมอ | EPS เพิ่มทุกปี | กำไรทุกปี ไม่แกว่งเกินครึ่ง | ขาดทุน/แกว่งแรง |
| OCF ÷ กำไร | > 1 | 0.7–1 | < 0.7 |
| หนี้สุทธิ ÷ ทุน | ไม่มีหนี้สุทธิ | < 0.5 | ≥ 0.5 |

**4. จัดกลุ่ม → เลือกวิธีประเมิน**
| ประเภท | เงื่อนไข | วิธีหลัก |
|---|---|---|
| วัฏจักร | กลุ่มพลังงาน/วัตถุดิบ, เคยขาดทุน หรือ EPS เคยลด > 20% ในปีเดียว | กำไรเฉลี่ย × P/E เหมาะสม |
| เติบโต | กำไรหรือรายได้โต ≥ 10% และจ่ายปันผล < 50% | DCF |
| ปันผล | จ่ายปันผล ≥ 50% | DDM + DCF |
| มั่นคง | นอกเหนือจากนี้ | DCF + กำไรเฉลี่ย × P/E |

- DCF ใช้ FCF ต่อหุ้นเฉลี่ย 3 ปี โต 5 ปีแรกตามอัตราเติบโตในอดีต (ไม่เกิน 20%) แล้วค่อยๆ ลดเหลือ 3% ใน 5 ปีถัดไป
- Reverse DCF: ราคาปัจจุบันสะท้อนว่าตลาดคาด FCF จะโตปีละเท่าไร

**5. สรุป**: คะแนน ≥ 7 = คุณภาพสูง และราคาต่ำกว่า Fair Value อย่างน้อยเท่า MOS = ราคาถูก

## การป้องกันข้อมูลผิด
- **แตกพาร์/หุ้นปันผล**: ปรับจำนวนหุ้นปีเก่าให้ตรงกับหน่วยหุ้นปัจจุบัน (เฉพาะเมื่อ Yahoo ยังไม่ปรับให้)
- **ข้อมูลบางปีว่าง**: คำนวณการเติบโตจากปีแรกที่มีข้อมูล และแจ้งว่าปีไหนว่าง
- **ไม่ทราบสกุลเงินของงบ**: ลองดึงซ้ำ ถ้ายังไม่ได้จะเตือน และเตือนอีกชั้นถ้า P/E ผิดธรรมชาติ (> 150 หรือ < 1)
- **ส่วนของผู้ถือหุ้นติดลบ**: ขึ้นสัญญาณเตือน และไม่ให้คะแนนด้านหนี้
- **ธนาคาร/ประกัน**: ขึ้นคำเตือนว่าผลไม่น่าเชื่อถือ
- **คำนวณมูลค่าไม่ได้**: สรุปว่า "ข้อมูลไม่พอ" แทนที่จะให้ผลที่ดูเหมือนปกติ
- ทุกกรณีมีชุดทดสอบใน `test_offline.py`

## ข้อจำกัด
- Yahoo Finance ไม่ใช่ API ทางการ งบมักย้อนหลังได้ราว 4 ปี และบางครั้งใช้ไม่ได้ชั่วคราว
- ใช้งบรายปีเท่านั้น กำไรล่าสุดอาจเก่าหลายเดือนเมื่อเทียบกับราคาวันนี้
- ไม่เหมาะกับธนาคาร/ประกัน
- ตรวจตัวเลขกับงบจริง (เว็บ SET) ก่อนใช้ทุกครั้ง
- เป็นเครื่องมือช่วยคัดกรอง ไม่ใช่คำแนะนำการลงทุน
